# HV Art Portfolio

A portfolio website showcasing HV artwork, creative projects and artistic styling

## Overview

A simple web portfolio designed to convey the HV design themes and establish a point of contact in a clean, visually engaging, and accessible format.

The website provides prospective clients with a central place to explore artwork and the artist, shop for prints, and request custom work. 

## Features
- Responsive layout for desktop and mobile devices
- Artwork gallery
- Contact Form

## Technologies Used

- TypeScript with Angular
- CSS
- HTML

## Design

This portfolio uses a minimalist layout and a muted color palette with layered paper textures.

The interface prioritizes clear navigation, readable typography and a responsive viewing experience.
